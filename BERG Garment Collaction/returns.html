BERG / CUSTOMER CARE

Returns &
Exchanges

Please contact BERG before sending an item back so we can review the request and explain the next step.

General returns

Contact BERG promptly if you would like to discuss returning an item. Return approval and arrangements will be confirmed case by case.

Exchanges

Exchanges may be considered where the requested replacement is available. Contact BERG before sending the item.

Incorrect sizes

If the size is not suitable, contact BERG to discuss an exchange. Availability and return condition will be considered.

Damaged products

Contact BERG as soon as possible with clear photos and order details if an item arrives damaged.

Incorrect products received

Do not use the incorrect item. Contact BERG promptly so the order can be checked and the next step arranged.

Items that may not be eligible

Items that are worn, washed, altered, damaged after delivery, or missing original tags or packaging may not be eligible. Eligibility will be reviewed with the order.

Condition of returned products

Items should be unworn, unwashed, unaltered, and returned in a condition suitable for inspection, with tags and packaging where applicable.

Customer responsibility

Customers should package returns securely and provide accurate return information. Do not send an item without confirming the return address and process with BERG.

How to contact BERG

Send your order details and a short explanation to WhatsApp or call 081 842 5151. Do not assume a return is approved until BERG confirms it.
